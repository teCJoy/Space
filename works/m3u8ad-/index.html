What to do next

You have downloaded an ad-free M3U8 playlist. Here are some ways to use it:

  • Download as MP4 using FFmpeg
    ffmpeg -allowed_extensions ALL -protocol_whitelist "file,http,https,tcp,tls,crypto" -i "clean_playlist.m3u8" -c copy -bsf:a aac_adtstoasc output.mp4
    Replace clean_playlist.m3u8 with the actual file path or URL. If the M3U8 uses relative paths, add -base_url "https://example.com/path/" before the -i.
    Download FFmpeg: https://ffmpeg.org/download.html
  • Convert to MP4 online – try these free tools:
    • Online-Convert
    • Convertio
    • FreeConvert
    • CloudConvert
    • Aconvert
    • HLSLoader (download as MP4)
  • Play locally – use any modern media player that supports HLS (e.g., VLC, IINA).
